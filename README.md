Research Area: Control and Automation Engineering/Railway Transportation

Software:MATLAB/Simulink

Status:In progress

Project Overview:
This project involves mathematical modeling, frequency, fleet and capacity analysis, and optimization and feedback and control strategies based on the results of the planned M13 Yenidoğan-Söğütlüçeşme rail system line, within the context of control and automation engineering and rail transportation.

Project Objectives:
1. To develop mathematical models for the system.
2. To optimize the relationship between service frequency and fleet under certain constraints.
3. To simulate train movements, departures, arrivals, and delays.
4. To design a feedback-based controller to be used in headway control.
5. To realize the objectives using MATLAB/Simulink software.

Project Development Stages:
1- Mathematical Modeling and Fleet/Headway Analysis
2- Capacity Analysis and Optimization Under Constraints
3- Dynamic Train Movements and Operation
4- Feedback Control Algorithm Design
5- Performance Measurement and Overall Analysis
6- Research Documentation and Reporting

Research Limitations and Principle of Integrity:
This study is conducted independently as an undergraduate student project. It is not a formally defined plan for the M13 line. All hypothetical values, model constraints, and data sources will be documented. Simulation results will not be presented as verified operating performance unless supported by appropriate real world data and validation.

Keywords: Railway Transportation, Railway Operations, Control and Automation Engineering, Headway Regulation and Control
